Este es un *tablero de gestión* unificado el cual se nutre de 3 archivos:

1. Excel de Comisiones (subir Month to Date).
2. Excel de Cluster (incluir Datos de cuenta, Apertura, AUM, Monedas CI, Comisiones 180 y Tipo de Cambio).
3. Excel de Tenencias (nos lo solicitan por los grupos comerciales).

El tablero tiene 4 páginas:

1. Resumen de comisiones del mes y ROA.
2. Resumen de AUM, Saldos deudores, y clientes con ROA bajo + liquidez.
3. Resumen de Tenencias.
4. Resumen de Tenencias consolidado por ticker.
